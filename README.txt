TEHNIKA v2.10

Implemented from the two latest accepted feature rounds:

RESULTS / SEARCH
- Active filter chips with individual remove and "clear all".
- Sorting: newest / price ascending / price descending remains functional.
- "Покажи още" pagination instead of endless scrolling (5 at a time in the prototype).
- City autocomplete for listing filters and publishing.
- Counts in brand/state/seller filter options.
- Zero-results screen with "remove last filter" and "clear all".
- Typo-tolerant search for common brands/categories/cities.
- Search synonyms for common appliance wording.
- Very short skeleton loading state.
- Lazy-loaded images + blur placeholder behavior.
- Responsive-image hooks are prepared; real raster srcset variants will be generated by the backend/image pipeline.

INACTIVE LISTINGS
- New listing-unavailable.html page for sold/expired listings.
- Keeps the old URL usable and offers similar active listings.
- noindex,follow is set on the inactive prototype page.

SAFETY / ACCOUNT
- Seller blocking persists locally across seller profile, listing and chat.
- Old chats remain visible while new contact is disabled.
- Seller profile reporting is exposed from seller/listing areas.
- Account security section in Profile:
  * change-email confirmation UI
  * password-reset UI
  * sign out all devices UI
  * recent important account activity

PUBLISHING ROBUSTNESS
- Required-field validation points directly to the problem field.
- Each step is checked before continuing.
- Final publish locks to prevent double publishing.
- Unsaved-change browser warning if the user accidentally leaves a started listing.
- Existing client moderation logic remains represented.

GENERAL UX
- Network/offline warning with retry.
- Small toast confirmations.
- Undo after removing a favorite.
- Short locks on favorite/follow/send/report/share/compare/security actions to prevent accidental repeated operations.

BACKEND NOTES
The frontend behavior is implemented now. The following become truly server-backed in the Supabase phase:
- real upload/network progress,
- real session revocation,
- real email confirmation/reset delivery,
- server-side block enforcement,
- server-side search/index counts,
- durable account activity logs,
- dynamic responsive image srcsets.
